# inkedbynnaya — landing page

React + Vite + Tailwind + framer-motion.

## Run
    npm install
    npm run dev       # local preview
    npm run build     # outputs ./dist  -> upload to Netlify / Vercel

## Edit
Everything lives in `src/App.jsx`. Contact details (WhatsApp, phone, address, TikTok, map) are at the top in the CONFIG block; services, hero slides and gallery are the `SERVICES`, `SLIDES`, `GALLERY` arrays. Photos are in `public/images`.
